# Termux Hacker Theme

![license](https://img.shields.io/badge/license-MIT-brightgreen)
![shell](https://img.shields.io/badge/shell-zsh-brightgreen)
Thème complet pour Termux : fond noir, texte vert, prompt Starship,
et différenciation claire des dossiers, fichiers et exécutables.

## Installation

```bash
git clone https://github.com/TON-PSEUDO/termux-hacker-theme
cd termux-hacker-theme
bash install.sh
```

## Désinstallation

```bash
bash uninstall.sh
```
