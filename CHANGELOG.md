# Journal des modifications

Toutes les modifications importantes de **Termux Hacker Theme** sont
documentées dans ce fichier.

## [À venir]

Cette section rassemble les changements prévus pour la prochaine version.

## [1.1.0] - 2026-08-21

### Ajouté

- Différenciation visuelle des dossiers, fichiers, liens et exécutables.
- Icônes de fichiers avec `eza --icons`.
- Alias `ls`, `ll`, `la`, `lt`, `cat`, `grep` et `matrix`.
- Configuration des touches supplémentaires de Termux.
- Configuration Starship enrichie pour le répertoire courant, Git, Python,
	Node.js et Rust.
- Configuration dédiée pour tmux.

### Modifié

- Amélioration de la lisibilité des couleurs pour les archives, scripts, fichiers
	de code, images et documents.

## [1.0.0] - 2026-08-21

### Ajouté

- Première version du thème Termux.
- Palette noire et verte, police et configuration du terminal.
- Configuration Zsh avec Oh My Zsh.
- Prompt Starship.
- Lancement de `fastfetch` à l’ouverture du shell.
- Alias `matrix` basé sur `cmatrix`.
- Configuration initiale de tmux.
